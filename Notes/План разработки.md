## Фаза 2. MVP (2–3 недели)
- [x] Модель и логика дат (`lib/features/payments/domain/payment_schedule.dart`, 30 тестов): следующая дата по периоду от исходного дня (`anchorDay`), 31-е → 30/28/29, переход через год, окончание кредита включительно, просрочка, дни до платежа, дата напоминания, прогноз на месяц (сумма + платежи с переменной суммой отдельно).
- [x] Репозиторий платежей на Drift (`data/payments_repository.dart`): добавить, изменить, удалить, «оплачено» (история + сдвиг даты), список с категориями. 19 тестов на базе в памяти.
- [x] Форма добавления/редактирования платежа: название, категория, сумма или «сумма меняется», период, дата, напоминание за N дней, дата окончания, заметка, удаление. Валидация, русский календарь.
- [x] Вкладка «Платежи»: список активных по дате, пустое состояние, кнопка «Добавить платёж». Виджет-тесты (добавление, переменная сумма, правка, удаление).
- [x] Каталог шаблонов РФ (`domain/payment_templates.dart`, 43 шаблона в 8 категориях): ЖКХ (сумма меняется, срок 10-го числа), кредит/ипотека, рассрочки («Долями», «Плайт», «Яндекс Сплит»), популярные подписки, связь, налоги (раз в год, 1 декабря, напоминание за неделю), ОСАГО/КАСКО и другие страховки, прочее. Цены не вписаны (тарифы меняются). В форме «Новый платёж»: быстрый выбор (7 чипов) и «Все шаблоны» с поиском. 33 новых теста.
- [ ] Шаблоны (доработка): пользовательские шаблоны («запомнить как шаблон»), цены популярных подписок после проверки актуальности.
- [x] «Ближайшие»: карточка «Нужно в этом месяце» (просрочка + остаток месяца, платежи с переменной суммой отдельной строкой), блок «Просрочено» сверху, затем платежи по датам с подписью «через N дн.»/«завтра»/«просрочено на N дн.». Кнопка «Оплачено» открывает диалог с суммой (подставлена обычная, для переменной пусто), пишет в `PaymentRecords`, двигает дату, показывает «Следующий: …» или «Платёж завершён». Правило: просрочка на несколько периодов считается один раз. 29 новых тестов.
- [x] «Ближайшие» (доработка): отмена оплаты и история оплат — сделано, см. ниже.
- [x] «Календарь»: сетка месяца с понедельника, точки категорий на днях (просрочено — красная, оплачено — бледная), переключение месяцев, кнопка «Сегодня», итоги месяца (запланировано / переменные суммы / оплачено), список платежей выбранного дня с переходом в форму. Оплаченные берутся из истории (`watchPaidBetween`) и стоят на день оплаты. 36 новых тестов.
- [ ] «Календарь» (доработка): оплаченные в прошлых месяцах показываются, но запланированные до ближайшей даты платежа — нет (расписание считается вперёд от `nextDueAt`).
- [ ] «Платежи» (доработка): группировка по категориям, пауза/архив, показ неактивных (выплаченных) платежей.
- [x] Локальные напоминания (`features/reminders/`): планировщик `planReminders` (за N дней в выбранное время, перенос на день платежа, одно напоминание о просрочке, горизонт 90 дней, ≤3 даты на платёж, ≤100 всего), синхронизация при любом изменении платежей/настроек, настройки в SharedPreferences (вкл/выкл, время), экран «Настройки» (разрешения, точное время, проверка уведомления). На Android: `flutter_local_notifications`, POST_NOTIFICATIONS запрашивается после первого добавленного платежа, SCHEDULE_EXACT_ALARM — по желанию пользователя (иначе неточный режим), пересоздание после перезагрузки штатным приёмником плагина. 54 новых теста логики и экранов. **Нужна проверка на телефоне** (сами уведомления, точное время, перезагрузка).
- [ ] Напоминания (доработка): по нажатию на уведомление открывать платёж; оценить `USE_EXACT_ALARM` против правил RuStore.
- [x] Настройки → «Данные»: резервная копия в JSON (все платежи, история, категории), восстановление из файла с подтверждением и полной проверкой файла до записи (транзакция, при ошибке данные целы), экспорт платежей и истории оплат в CSV (разделитель `;`, UTF-8 с BOM, защита от формул Excel). Системные диалоги через `file_picker`. 99 новых тестов (формат, CSV, репозиторий, сервис, экран).
- [x] Настройки → «Оформление»: тема «Система / Светлая / Тёмная», сохраняется на устройстве и действует с запуска.
- [x] Отмена оплаты: в сообщении после «Оплачено» кнопка «Отменить» (8 секунд). Откат удаляет запись истории и возвращает дату и активность платежа; если платёж уже меняли или оплачен ещё раз, отмена отказывает и ничего не затирает.
- [x] История оплат платежа: раздел в форме редактирования (итог «Всего оплачено… · N оплат», последние 12 оплат, новые сверху).
