## Что готово в проекте
- Иконка: адаптивная (`mipmap-anydpi-v26`) + запасные PNG; для магазина `store/icon-512.png` (512×512).
- Подпись релиза: ключ `C:\Users\CENTICORE\ezhemesyachno-signing\upload.jks`, параметры в `app/android/key.properties` (оба вне git). Без `key.properties` release подписывается отладочным ключом.
- Политика конфиденциальности: `docs/privacy.html` (нужно подставить имя и почту и разместить по ссылке, см. ниже).
- Тексты для карточки: ниже. Скриншоты: `store/screenshots/` (4 шт., 1080×2400, тестовые данные из демо-копии).
- Релизная сборка: `store/ezhemesyachno-1.0.0.apk` (63 МБ, универсальная, подпись нашим ключом, интернет-разрешения нет, R8 включён). Проверена в эмуляторе: запуск, база, восстановление из файла. Файл в git не попадает.
- Сборка заново: в терминальной панели `flutter build apk --release` (см. CLAUDE.md); версию менять в `app/pubspec.yaml` (`1.0.0+1`: после плюса номер сборки, при каждой новой загрузке увеличивать).

## ⚠️ Ключ подписи — не потерять
Сделайте копию `upload.jks` и пароля из `key.properties` в надёжное место (облако с паролем, флешка). Без ключа обновить приложение в RuStore будет нельзя: придётся публиковать под новым пакетом. В git и в память ключ не класть.
Проверено по справке RuStore (2026-10-16): отдельного механизма подписи от RuStore нет, магазин рекомендует свой локальный сертификат, то есть наш ключ подходит. Все следующие версии должны быть подписаны **тем же** ключом, пакет тот же, номер сборки больше. При потере ключа менять сертификат можно только через поддержку RuStore (support@rustore.ru), и все версии придётся загружать заново.

## Карточка приложения (предложение)
**Название:** Ежемесячно: календарь платежей

**Краткое описание (до 80 символов):** Календарь регулярных платежей и подписок. Без регистрации, офлайн.

**Полное описание:**
Ежемесячно — календарь ваших регулярных платежей. Подписки, коммуналка, кредиты и ипотека, рассрочки, налоги, страховки: всё в одном месте, с напоминанием заранее.

Что умеет:
• Ближайшие платежи и сумма «сколько нужно заплатить в этом месяце»
• Просроченные платежи сверху, отметка «Оплачено» одним нажатием, отмена по ошибке
• Календарь по месяцам с итогами по дням
• Напоминания за 1, 3, 7 дней и в день платежа — работают без интернета и после перезагрузки телефона
• 43 готовых шаблона: ЖКХ, интернет, Яндекс Плюс, налог на имущество, ОСАГО и другие
• Переменные суммы (электричество, вода): сумма запрашивается при оплате
• Кредиты и рассрочки с датой окончания
• История оплат по каждому платежу
• Экспорт в CSV и резервная копия в файл
• Светлая и тёмная тема

Приватность: данные хранятся только на вашем устройстве. Регистрации нет, интернет не нужен, рекламы нет.

**Категория:** Финансы (запасной вариант: Инструменты) · **Возраст:** 0+
**Теги (не более 5):** платежи, подписки, напоминания, ЖКХ, кредиты

**Что нового в 1.0.0:** Первый выпуск.

## Требования консоли (проверено по справке RuStore, 2026-10-16)
- Приложение в консоли может добавить только владелец аккаунта. Шаги: «Приложения» → «Добавить приложение» → имя → «Загрузить версию» (APK или AAB, до 5 ГБ) → на модерацию или в черновик. Первую версию загружать вручную.
- Название **до 30 символов**, уникальное (наше «Ежемесячно: календарь платежей» ровно 30). Краткое описание до 80, полное до 4000 символов.
- Иконка: 512×512, PNG/JPG, до 3 МБ, без прозрачных краёв (`store/icon-512.png` подходит).
- Скриншоты телефона обязательны: минимум 3, PNG/JPG, до 3 МБ, максимум 2160×3840 (наши 4 шт. 1080×2400 подходят).
- Нужны: категория, возрастной рейтинг, контакт разработчика (почта достаточно), блок «Безопасность данных» (категории данных и чувствительные разрешения), «Что нового».
- Для блока «Безопасность данных»: мы не собираем и не передаём данные, всё хранится на устройстве; разрешения: уведомления, точные будильники, запуск после перезагрузки.
- Ссылка на политику: `https://viktor-cska.github.io/Mobile_app/privacy.html` (страница проверена, 2026-10-16).
- Срок модерации и требование ссылки на политику на странице справки не указаны: смотреть в консоли.

## Проверки перед отправкой
- Разрешение `SCHEDULE_EXACT_ALARM` объявлено; без разрешения напоминания идут неточно. В описании упомянуть, что точное время включается в настройках телефона.
- Интернет-разрешения в релизной сборке нет (проверить `aapt dump permissions`).
