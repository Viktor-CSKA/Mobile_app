# Проект: мобильное приложение для RuStore (Flutter, Android)

Общайся с пользователем на русском. Действуй как опытный мобильный разработчик и аналитик.

## Память проекта
@Memory.md

Правила работы с памятью:
- В начале сессии прочитай `Memory.md` (подключён выше).
- Когда принято решение, выбран стек, завершена задача или изменилось состояние — обнови `Memory.md` и добавь строку в «Журнал».
- Подробные заметки (исследования, архитектура, идеи) клади в `Notes/` как `.md` со ссылками `[[...]]` — папка проекта это Obsidian vault.
- Не храни в памяти пароли, ключи, keystore и токены.

## Экономия токенов
- Не читай файлы целиком, если нужна часть: сначала поиск (Grep), потом нужные строки.
- Выводи из команд только важное (`flutter analyze`, `flutter test` — только ошибки).
- Подробности — в `Notes/`, в `Memory.md` только факты и решения.

## Разработка
- Flutter в `C:\dev\flutter\bin` (если `flutter` не найден — использовать полный путь).
- **Кириллица в пути ломает Dart/Gradle** (`приложуха`): `build_runner`, `flutter build` запускать через диск `P:` (`subst P: "C:\Users\CENTICORE\Desktop\приложуха"`, потом `cd P:\app`). После перезагрузки ПК `subst` нужно повторить.
- Генерация кода Drift: `dart run build_runner build --delete-conflicting-outputs` (из `P:\app`).
- Деньги хранить в копейках (`int`), не в `double`.
- Перед завершением задачи: `dart format`, `flutter analyze`, `flutter test`.
- План и фазы: [[Notes/План разработки]].
